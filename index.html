Features · F1–F10

你日常要开五个工具做的事，这里一个窗口搞定。

每一项都不是「计划中」，而是产品需求文档 F1–F10 逐条落地后的现状。

F1

终端会话

xterm.js WebGL 渲染，多标签与状态栏（协议 / 地址 / 延迟 / 加密套件 / 尺寸），⌘F 搜索输出，断线指数退避自动重连，多行粘贴护栏。

F2

主机管理

分组 + 标签 + 搜索，一键连接。每 30 秒 TCP 测时实时显示延迟，删除分组时组内主机自动迁移不丢失。

F3

SFTP 文件传输

双栏浏览，上传 / 下载队列带进度、速率与失败重试。断点续传前比对两端前 1MB 的 SHA-256，不一致自动从头重传。

F4

密钥管理

生成 Ed25519 / RSA 4096，导入、指纹、复制公钥、使用统计。私钥经设备密钥加密落库，设备密钥存系统 Keychain。

F5

端口转发

L 本地 / R 远程 / D 动态 SOCKS5 三类真实转发，实时流量统计，应用启动时自动恢复已启用的规则。

F6

命令片段

片段库 + 终端右栏快捷面板一键运行，支持 {{cursor}} 占位符停留待编辑。

F7

端到端加密云同步

oplog 增量同步，逐条 XChaCha20-Poly1305 加密并将对象路径绑定为 AAD；实体级 LWW + lamport 时钟、删除墓碑、每设备游标增量拉取。30 天自动压实为加密快照，新设备秒级引导。管理平台只下发按用户前缀收敛的 STS 临时凭据，桶内只有密文，平台零知识。忘记主密码可凭 24 词 BIP39 恢复短语找回。

F8

会话录制与回放

asciicast v2 格式录制，状态栏 REC 计时；内建回放器支持播放 / 暂停 / 进度拖动 / 1–4× 倍速。

F9

命令面板

⌘K 唤起，统一搜索主机、片段与动作，键盘不离手完成一切跳转。

Monitor

服务器监控

经 SSH 直接采样 CPU / 内存 / 磁盘 / 负载 / 网络，远端无需安装 agent。

F10

设置与主题

深 / 浅主题、终端字号、光标闪烁，启动恢复会话、断线自动重连、退出前确认等行为开关，附完整快捷键表。

Security

known_hosts 指纹校验

TOFU 首连记录；指纹变更即刻中断连接并告警，必须显式「信任新指纹」才允许重试。

AI Assist

在命令行直接敲白话，回车就变成命令。

识别规则偏保守：首词是已知命令、含管道或选项、路径、环境变量赋值一律按命令原样执行；只有确认不是 shell 命令的句子才交给 AI。生成的命令必须经你确认才会写入终端。

  • 模型自由选择，多协议并存配置多个模型随时切换，按所选模型的协议请求对应接口。各模型密钥经设备密钥分别加密存本地。
  • 三个入口，都在终端里右下角常驻 AI 图标（当前行有内容就直接翻译，空行则唤起输入框）；⌘⇧A 主动生成命令；⌘I 让 AI 解释最近输出。
  • 右栏对话可读会话输出回复中的命令一键「在终端运行」。取消翻译时原文保留，不丢一个字的输入。
anthropic /v1/messages openai 兼容 · OpenAI / DeepSeek / OpenRouter / vLLM ollama 本地 · 无需密钥
白话 → 命令 · 完整流程 ⌘ ⇧ A⌘ I
1
直接在命令行输入一句话

例如 找出占用 8080 端口的进程并杀掉，回车。想强制走 AI 可加 ? 前缀。

2
保守规则先判定是否为 shell 命令

已知命令 / 管道 / 选项 / 路径 / 变量赋值 → 原样执行；否则交给当前选中的模型。

3
模型返回命令，等待你确认

可选「填入」（不回车）或「直接运行」。破坏性命令显著告警：

kill -9 $(lsof -t -i:8080) · 会终止进程，请确认
4
采纳则替换该行，取消则原样保留

整个功能可在设置中关闭；管理平台也能统一下发「AI 助手」开关。

At rest

XChaCha20-Poly1305 + Argon2id

私钥、AI 密钥、同步数据全部经此加密落库。设备密钥存系统 Keychain，不可用时回退 0600 文件。

In transit

STS 限权临时凭据

平台以 session policy 把权限收敛到 users/{id}/*，1 小时有效。跨前缀访问直接被拒。

Zero knowledge

主密码只在本地派生密钥

桶内仅密文，manifest 以主密钥加密并用 If-Match 乐观锁。平台拿不到任何明文，也不需要。

Recovery

BIP39 恢复短语

24 词即主密钥。忘记主密码时凭短语在任意设备恢复，跨设备一致。

Host trust

known_hosts TOFU

首连记录指纹，之后指纹一变即中断并告警，必须显式信任新指纹才可重试。

Migration

设备密钥自动迁移

历史 device.key 作为解密兜底，存量密文逐条改用当前密钥重加密，全部成功才删旧文件。

Security Model

凭据留在你的设备上，云端只见密文。

KiteTerm 不做「先上传再说」。所有需要出设备的数据都先在本地加密，管理平台的角色只是账户中枢与凭据分发者。没有平台放行，登录和云同步就是用不了，这是服务端硬约束而不是客户端自觉。

  • 不需要 KiteTerm 官方服务器管理平台是一个独立的 Rust axum 二进制，配上任意 S3 兼容存储（MinIO 也行）即可自托管。
  • 不配平台也能完整使用纯本地用户从未连过平台时，四项功能开关默认全开，不会被一套你从未启用的管控挡住。
  • 登录错误不泄露邮箱是否存在登录开关校验放在口令校验之后；注册按 IP 滑动窗口限流并前置于校验，防止邮箱枚举。

从源码构建桌面端

在 macOS 上产出 .app / .dmg；在 Windows 上产出 .msi / .nsis，需在对应系统执行。

shell
git clone https://github.com/xltxb/KiteTerm.git
cd KiteTerm
pnpm install:desktop          # 等价于 pnpm -C desktop install

# 开发运行(唯一的运行方式;浏览器直接打开只会看到提示页)
KITE_NO_KEYCHAIN=1 pnpm tauri dev

# 打包
pnpm tauri build

自托管管理平台（可选）

只有需要账户与云同步时才要它。S3 指向任意兼容存储，例如本地 MinIO。

shell

S3_ACCESS_KEY=<ak> S3_SECRET_KEY=<sk> \

FAQ

常见问题

有 Web 版或 Linux 版吗？
目前没有 Web 版：SSH / SFTP / 密钥 / 同步能力都由本地 Rust 核心提供，前端只在 Tauri WebView 内运行，用浏览器打开开发服务器只会看到提示页。官方构建目标为 macOS 与 Windows。
云同步必须用官方服务器吗？
不需要。管理平台是仓库 server/ 目录里的一个独立 Rust 二进制，配上任意 S3 兼容存储即可自托管。应用内「同步」页默认平台地址为 http://127.0.0.1:8787，可在「设置 → 管理平台」修改。
AI 协助会把我的终端内容发出去吗？
只有你主动触发时才会请求模型：在命令行敲白话回车、点终端右下角 AI 图标、按 ⌘⇧A 或 ⌘I，或在右栏对话中提问。请求直接发往你自己配置的模型接口（Anthropic、OpenAI 兼容或本地 Ollama），密钥经设备密钥加密存本地。整个功能可在设置中一键关闭。
服务器监控需要在远端装 agent 吗？
不需要。监控经 SSH 直接采样。采样命令面向 Linux 远端（读取 /proc），macOS 远端目前显示为离线。
忘记同步主密码怎么办？
启用同步时会生成 24 词 BIP39 恢复短语，它等价于主密钥。凭短语可在任意设备恢复并解密同步数据。主密码仅在本地派生密钥，平台无法帮你重置，请妥善保管短语。
为什么开发时建议加 KITE_NO_KEYCHAIN=1？
每次重新编译都会产生新二进制，系统钥匙串会视其为新程序而反复弹出授权框。该开关让设备密钥走 0600 文件回退。应用启动时会自动做设备密钥迁移，把历史文件密钥加密的数据换用当前密钥，不会出现「解密失败（设备密钥不匹配）」。
项目的许可证是什么？
源码公开在 GitHub 仓库，许可证以仓库内声明为准。
